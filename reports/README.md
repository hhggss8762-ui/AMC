# 验证结果索引

本目录只纳入精选结果，不包含仿真数据集、训练中间检查点、真实 IQ、内部请求样例或容器完整导出记录。报告为实验发生时的历史记录，其中的“尚未整合”“未上传”等描述仅代表当时阶段；项目当前状态以[项目首页](../README.md)为准。

## 仿真结果

当前 20 类版本的测试、0.5 阈值、容器回归和远端镜像摘要见 [0.1.1 发布记录](signal_recognition_011_release/REPORT.md)。下表为原 13 类基线的历史结果。

| 实验 | 报告 | 主要结果 |
|---|---|---|
| 冻结模型独立单窗口测试 | [训练报告](full_baseline_v1/TRAINING_REPORT.md) | 15～30 dB：95.0449%；0～30 dB：87.1136% |
| 1,820 段连续长信号配对评估 | [长信号报告](long_signal_v1/LONG_SIGNAL_REPORT.md) | 15～30 dB：中间单窗 94.71%、五窗 97.88% |
| 100 kHz～20 MHz，7,280 段独立信号 | [带宽报告](bandwidth_sweep_v1/BANDWIDTH_REPORT.md) | 15～30 dB：五窗合并 98.27% |

所选子目录包含主要图表、`evaluation/metrics.json`、混淆矩阵及结果审计 JSON。训练报告里的 `evaluation/predictions.npz`、训练日志，长信号/带宽报告里的完整 `signal_results.jsonl`、预测数组和源数据只在本地保留，没有上传；不能只凭仓库中的汇总文件重做所有逐样本审计。需要重新评估时先按配置生成对应数据。

所有准确率均为独立仿真结果，不代表真实接收机效果；OFDM、采样率范围和耗时统计边界以各报告为准。部分机器路径是实验溯源信息，不是运行脚本所需的固定安装位置。
