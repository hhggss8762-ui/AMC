# 数据契约

主类别顺序固定在 configs/baseline.yaml 与 amc.config.CLASSES。
每个数据集的 manifest.json 携带同一类别顺序；后续模型必须携带类别表。
PI4_DQPSK 是 π/4-DQPSK 的 ASCII 标识，不是新增类别。
OFDM 追加为 ID 12，原 ID 0-11 保持。读取旧 12 类数据时使用其 manifest
中的类别表，不能用新类别数猜测旧数组形状。

输入布局 N×2×2048，float32；通道 0=I，通道 1=Q。
功率归一化定义 mean(I²+Q²)=1，不是分别把两个通道方差设为 1。
实际输出采样率、名义带宽与窗口物理时长在 metadata.jsonl。

训练、验证、测试按独立源波形生成。一个源波形未来若切出多个窗口或派生多个
SNR 版本，必须保持同一划分。不可依靠相邻窗口随机拆分训练/测试。
每档样本数量固定；AM DSB_LC/SSB 和 ASK OOK/BINARY_NONZERO 均分。
SSB 内随机选择 USB 或 LSB，均贴 AM 标签。
OFDM 子载波星座是生成参数，主标签仍为 OFDM；单载波 QPSK/QAM 标签独立。
FFT 长度、CP、有效子载波数、子载波间隔、星座和窗口覆盖的符号时长均记录。
preview/full 使用不同种子命名空间，避免后续训练通路检查接触正式测试波形。

审计涵盖数据形状、dtype、有限值、单位 RMS、类别/SNR/子类型数量、
源种子唯一性、标签映射，以及保存的 clean/noise 分量对 SNR 的独立复算。
审计通过表示数据契约满足，不表示模型已达到 95%。

## 连续长信号测试数据

data/long_signal_v1 是独立新增测试集，不修改上述训练窗口。每个 signals/*.npz
保存一段连续原始 complex64 IQ 及 input_metadata_json（采样率、中心频偏、估计带宽、测试用有效长度）。
真实标签、SNR、生成参数及种子只在 metadata.jsonl，不进入推理接口。
原始长度不统一；处理后居中保留 16384 有效点，再按固定位置取五个 2048 点窗口。
整段只设置一次带内噪声比例，窗口 SNR 自然波动。信号数为 1820，选中窗口数 9100，
主要评估统计单位是独立信号数。种子命名空间 3，preview/full 再区分命名空间。
原始文件 SHA256、共享预处理重放、源种子、标签/子类型数量和 15 个原始分量参考文件均已审计。
详细输入约定和短记录处理见 docs/LONG_IQ_INFERENCE.md。
